1. INTRODUCTION                                            *beamer2html-intro*

beamer2html turns a beamer deck written with beamer2html.sty into an HTML
slide deck (slides.html). This plugin runs it from Neovim: builds and the
--watch mode run in the background, warnings go to the |quickfix| list at the
slide they concern, and the browser can be opened at, or moved to, the slide
under the cursor -- like SyncTeX forward search.

The main .tex file is found automatically: the current file if it contains
\documentclass, otherwise main.tex in the file's folder or a parent folder.
Set |g:beamer2html_main| (or b:beamer2html_main) to choose another.

Requires Neovim 0.10+, Python 3, and the beamer2html repository this plugin is
part of (the plugin finds the tool through its own location).

==============================================================================
2. COMMANDS                                             *beamer2html-commands*

:Beamer2Html                                                    *:Beamer2Html*
        Save all buffers and build slides.html. Warnings go to the quickfix
        list (|:copen|), each at the source line of its slide.

:Beamer2HtmlWatch                                          *:Beamer2HtmlWatch*
        Start `beamer2html --watch` in the background, or stop it if it runs.
        The deck rebuilds on every save; an open deck reloads itself and
        stays on its slide. Each rebuild refreshes the quickfix list.

:Beamer2HtmlStop                                            *:Beamer2HtmlStop*
        Stop watching. Watching also stops when Neovim exits.

:Beamer2HtmlOpen                                            *:Beamer2HtmlOpen*
        Open slides.html in the browser at the slide (and \pause step) under
        the cursor.

:Beamer2HtmlSync                                            *:Beamer2HtmlSync*
        Move the deck that is open in the browser to the slide and step under
        the cursor. Works while watching (the deck must be built in watch
        mode); see also |beamer2html-autosync|.

:Beamer2HtmlPack [{zip}]                                    *:Beamer2HtmlPack*
        Save all, build, and write a zip with the deck and only the files it
        uses, for the presenting computer. Default: slides.zip next to
        slides.html.

:Beamer2HtmlLog                                              *:Beamer2HtmlLog*
        Show the output of the last build or of the running watch.

:Beamer2HtmlNew {dir}                                        *:Beamer2HtmlNew*
        Copy the starter template (all templates, with placeholders) to {dir}
        and open its main.tex. {dir} must not exist or be empty.

==============================================================================
3. MAPPINGS                                             *beamer2html-mappings*

In tex buffers (filetype tex), unless `mappings = false`:

  <localleader>mb    |:Beamer2Html|          build
  <localleader>mw    |:Beamer2HtmlWatch|     watch on/off
  <localleader>mo    |:Beamer2HtmlOpen|      open the deck at the cursor
  <localleader>ms    |:Beamer2HtmlSync|      move the open deck to the cursor
  <localleader>mp    |:Beamer2HtmlPack|      zip for presenting
  <localleader>ml    |:Beamer2HtmlLog|       show the output

==============================================================================
4. CONFIGURATION                                          *beamer2html-config*

Defaults: >lua
    require("beamer2html").setup({
      python   = "python3",
      tool     = nil,            -- the beamer2html folder; default: this repo
      main     = nil,            -- main .tex file; default: found by itself
      output   = "slides.html",
      browser  = nil,            -- e.g. "firefox"; default: xdg-open / open
      autosync = false,          -- follow the cursor while watching
      mappings = true,
    })
<
                                                          *g:beamer2html_main*
g:beamer2html_main / b:beamer2html_main
        Path of the main .tex file, overriding the automatic choice.

                                                        *beamer2html-autosync*
With `autosync = true`, while watching, the deck follows the cursor: after
the cursor rests (|CursorHold|, see 'updatetime') on another slide, the deck
in the browser moves there.

==============================================================================
5. STATUSLINE                                         *beamer2html-statusline*

`require("beamer2html").status()` returns "beamer2html: watching" while the
watch runs, "" otherwise. For vim-airline: >vim
    let g:airline_section_x = '%{v:lua.require("beamer2html").status()}'
<

6. SNIPPETS                                             *beamer2html-snippets*

With LuaSnip installed, these snippets are added for tex files. Type the
trigger, choose it from the completion menu (or expand it), then <Tab>
through the fields; the default values can be accepted or typed over.

  frame      \begin{frame}{Title} ... \end{frame}
  framesub   frame with title and subtitle
  cols       two columns (0.48\textwidth each)
  rows       two rows (0.4 / 0.6 of the slide body)
  block      \begin{block}{Title} ... \end{block}
  stab       slidetable (style striped|plain|lines|header, header row)
  lit        litreview with one \study
  study      \study{keys}{finding}
  prog       progress with one \task (done|ongoing|planned)
  task       \task[status]{what}{when}
  pubs       publications with a \pubsection and a \pub
  pub        \pub[status]{key}
  note       \note{...}
  fig        \includegraphics[width=\linewidth]{figures/...}
  figcap     figure with \caption and \label (fig:...)
  tabcap     table with \caption above a slidetable, \label (tab:...)
  anim       figure with an animation environment (\animpanel, \N) and caption
  video      figure with a \slidevideo (poster) and caption
  plot       slideplot with a \plotline (columns x, y of a data file)
  panels     slideplot with \plotpanel panels (shared axes, one legend)
  annot      figure with an annotate environment (grid on) and a \shape
  shape      \shape[color=..]{kind}{x1,y1}{x2,y2}
  sshape     \slideshape[color=..]{kind}{x1,y1}{x2,y2}
  axes       \shape[..]{axes}{x,y}{length}: coordinate axes indicator
  flow       tikzpicture with flowstart / flowbox nodes and a flowarrow

For any other environment, the `begin` snippet of friendly-snippets gives
\begin{name} ... \end{name}, typing the name once (load friendly-snippets
with `require("luasnip.loaders.from_vscode").lazy_load()`).
